The `MediaOverview` is registered with the key `sulu_media.overview`. It shows a list of available medias
presented in a masonry layout and a list of collections above of that. It is built from a
[`MediaCollection`](#mediacollection) and binds `locale`, `id` (the collection), `collectionPage`, `mediaPage` and the
list settings (limit, sort column, sort order, filter) to the router attributes.

This view has no route options.
